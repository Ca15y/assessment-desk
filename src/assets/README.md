# Naira glyph font

`NotoSans-Regular.ttf` is used only for the naira currency glyph in Demand Notice PDFs. Other text retains the prototype's Helvetica 9 pt.

Source: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Downloaded from the official Noto repository on 28 September 2026. The accompanying `NotoSans-LICENSE.txt` contains the SIL Open Font License 1.1. The font is served locally with the application; rendering sends no document data or font requests to external services. It was not extracted from the owner's document.
